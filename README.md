CareerCraft 🚀

Professional Resume & LinkedIn Setup for Students

CareerCraft is a modern, responsive static website built to help students create internship-ready and ATS-friendly resumes along with optimized LinkedIn profiles.

This project is designed to collect student service requests through a clean and simple web interface and is fully deployable using GitHub Pages.

🌟 Features

Professional landing page design

Service pricing section

Structured “How It Works” process

Order request form (static – GitHub Pages compatible)

Smooth scrolling navigation

Mobile responsive layout

Clean and modern UI

Zero backend required

💼 Services Offered

Resume Formatting (ATS-friendly)

Resume + LinkedIn Bio Optimization

Complete Profile Setup (Resume + LinkedIn + GitHub)
